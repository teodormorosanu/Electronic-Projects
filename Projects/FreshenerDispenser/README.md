# Freshener Dispenser

> **❌ DEPRECATED: This project is no longer actively maintained. The documentation and files are displayed here only for archival and reference reasons.**

## Overview

**Theme:**
*3D Printed Freshener Dispenser, Embedded Systems, Hardware & Automation*.

**Objectives:**
- To address and resolve the **bad smells** in home problem.
- To implement a **reliable system** while keeping a pleasant and warm design.

---

**Description:**
This project was designed as an automated air freshener dispenser, implementing interval timing with mechanical actuation.

The most interesting parts of the project are the **`time management`** and **`mechanical actuation`** systems. At the base of the build is the **`time management`** system. Implemented in the core electronics, it uses an RTC (Real-Time Clock) module to track the passing time. Based on the schedule, it initiates the dispensing to ensure the environment always smells fresh.

Once a scheduled interval is reached, the **`mechanical actuation`** system comes in place. The device has a simple mechanism utilizing a motor. The motor translates physical force, pressing down on the spray canister to release a burst of parfume exactly when intended.
