# Components

A centralized collection of reusable design assets and standard parts used across the various projects in this repository. This library is designed to speed up the drafting process and ensure consistency between different builds.

## Categories

| Category | Description | Status |
|---|---|---|
| [2D](./2D) | Vector graphics and UI elements used for wiring diagrams. | 🔄 Active |
| [3D](./3D) | Standardized CAD models library used in the projects. | 🔄 Active |

## Structure

Each components category typically includes:

- **`Electronic`** and **`Mechanical`** folders: 
  - `/<component_type>` - Contains standard flat formats (`.svg`) or CAD models (`.f3d`).
